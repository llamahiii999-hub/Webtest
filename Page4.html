Infinite Art

On this webpage, you can play Infinite Art by Llama Dev, a game made using GDevelop. This game was created for fun, and is not a serious art program. In Infinite Art, you use different tools to draw. After you are done drawing, clicking the save button will save your art. Then, using the save menu, you can reload your art. You have the ability to change the color with the RGB color system. You can change the size of your pen to draw thicker or thinner lines. Using the eye drop tool lets you select a color you have already used. The trash can allows you to erase a spot where you have drawn. Pressing the delete key on your keyboard, clears what you have drawn. Moving the arrow keys allows you to view more of the canvas.
